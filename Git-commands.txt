Command
What it does

git init
Initialize a new Git repository

git clone <url>
Download a remote repository

git status
Show the state of your working directory

git add <file>
Stage a file for commit

git commit -m "msg"
Save a snapshot with a message

git push origin main
Upload commits to remote

git pull origin main
Download and merge remote changes

git branch <name>
Create a new branch

git checkout <branch>
Switch to a branch

git log
View commit history
